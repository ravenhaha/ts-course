# TypeScript: домашние задания и итоговый проект

В репозитории находится **[Budget Tracker CLI](budget-tracker-cli/README.md)** — интерактивное консольное приложение для управления личными финансами.

```sh
cd budget-tracker-cli
npm install
npm start
```

Нужен Node.js 22 или новее. Меню работает в обычном терминале: выбор стрелками, подтверждение Enter.

Реализованы список и создание счетов, просмотр транзакций, добавление с валидацией, удаление с подтверждением и экспорт CSV. Данные хранятся в памяти в пределах запуска приложения.

- [Инструкция, структура и проверка требований итогового задания](budget-tracker-cli/README.md).
- [Исходное итоговое задание](budget-tracker-cli/docs/assignments/final-project.pdf).
- [Выполненные темы 1–12 и их версии](budget-tracker-cli/README.md#все-домашние-задания).
- Итоговая версия: тег `final-project`. Ранние решения: `topic-01`…`topic-12`.

Проверки: `npm test` в папке `budget-tracker-cli`. Учебные примеры: `npm run demo`.
