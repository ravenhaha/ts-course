# Budget Tracker CLI

Учебное консольное приложение для учёта личных финансов. Домашние задания выполняются последовательно в одном проекте. Каждый завершённый этап сохраняется отдельным коммитом и тегом `topic-NN`.

Условия преподавателя сохранены без изменений в [docs/assignments](docs/assignments). Источник: https://github.com/vovachebr/TypeScript-homeworks.

## Запуск

```sh
npm install
npm run build
npm start
```

Тема 2: `node dist/calculation-demo.js` после сборки. Ожидаемые результаты: чистый доход 25000, остаток 15000.

Тема 3: `node dist/functions.js`. Демонстрируются все пять функций; среднее пустого массива равно 0.

Тема 6: `node dist/generics.js`. Хранилище продуктов, безопасный вызов `describe`, поиск, удаление и копия массива.

## Завершённые этапы

| Тема | Содержание | Версия |
| --- | --- | --- |
| 1 | Настройка TypeScript и приветствие | Исходный коммит `8204991` |
| 2 | Базовые типы и вычисления | `topic-02` |
| 3 | Типизированные функции без объектов | `topic-03` |
| 4 | Интерфейсы, типы и объекты без классов | `topic-04` |
| 5 | Классы Transaction, Account, AccountManager | `topic-05` |
| 6 | GenericStorage и Product | `topic-06` |
| 7 | Общий namespace BudgetTracker, отдельные файлы | `topic-07` |
| 8 | Модули ES, uuid, moment, собственные декларации | `topic-08` |
| 9 | Утилитные типы и частичное обновление | `topic-09` |

Тема 9: `npm start` показывает все утилитные типы и частичные обновления. `update()` изменяет только данные, сохраняя методы и идентификаторы; попытка заменить идентификатор приводит к ошибке.

Начиная с темы 8, `npm start` запускает исходники через `tsx`, а `npm run build` и `npm run start:compiled` — сборку через TypeScript и Node.js. JavaScript-библиотека копируется в `dist` благодаря `allowJs`; рядом с исходниками находятся собственные `.d.ts`. Настроен alias `formatCurrency`; в классах используются относительные импорты с `.js`, чтобы собранное приложение запускалось непосредственно в Node.js.

Идентификаторы счетов и транзакций — строки UUID. Приватное поле `_id` и публичный getter `id` сохраняют инкапсуляцию и совместимость с интерфейсами: приватное поле с именем `id` не могло бы реализовать публичное поле интерфейса.

В теме 7 выбран итоговый чек-лист преподавателя: общий `namespace BudgetTracker`, объединение деклараций, `reference`, `module: none`, сборка в `dist/budget-tracker.js`. Пример с ES-импортами в середине условия противоречит этому чек-листу; переход на модули предусмотрен темой 8. TypeScript закреплён на 5.9.3: версия 7 удаляет необходимые для темы 7 настройки `outFile` и `module: none`. Старые демонстрации собираются отдельно через `tsconfig.demos.json`.

Темы 4–5 запускаются через `npm start`: добавление, поиск, удаление счетов и транзакций, расчёт сводки. В теме 4 вместо ещё не существующего класса `Account` используется `IAccount`, как в шаблоне преподавателя. В теме 5 `ISummary` содержит числовые итоги; название и количество транзакций выводятся через `getSummaryString()`. Сохранены оба имени `getAccounts()` и `getAllAccounts()`, поскольку условие использует оба.

## Как открыть отдельное ДЗ

Из корня репозитория:

```sh
git switch --detach topic-02
cd budget-tracker-cli
npm install
npm run build
node dist/calculation-demo.js
```

Возвращение к последней версии: `git switch -`. Перед переключением сохраните свои изменения. У каждого этапа собственная инструкция запуска в README.
